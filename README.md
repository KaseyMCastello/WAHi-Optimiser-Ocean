# WAH-*i* Ocean — Hydrophone Array Design & Optimisation for Whale Localisation

A fork of [WAH-*i*](https://github.com/raviumadi/WAHi-Optimiser) (Ravi Umadi, 2026, GPLv3), the
array-geometry optimiser originally written for microphone arrays and echolocating bats.
This version replaces the in-air bat model with an underwater one: **hydrophones, bathymetry,
sound-speed profiles, transmission loss, ambient noise, detection thresholds and whale calls**,
with fields of accuracy out to **100 km**.

Original paper: Umadi (2026), *WAH-i: Optimising Microphone Array Geometry for Customised
Localisation Accuracy*. https://doi.org/10.64898/2026.02.07.704547
